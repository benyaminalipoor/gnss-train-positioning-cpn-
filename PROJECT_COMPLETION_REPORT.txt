IMPLEMENTATION DETAILS
═══════════════════════════════════════════════════════════════════════════

CPN Model Structure:
  ├─ Top Level
  │  ├─ GNSS Receiver
  │  │  ├─ Open Area Scenario
  │  │  ├─ Mountain Occlusion Scenario
  │  │  └─ Tunnel & Exit Tunnel Scenario
  │  ├─ Position Solution (EKF)
  │  └─ Evaluation Module

Color Sets (Data Types):
  • SIGNAL           - Satellite signal data
  • SIGNALlist       - List of signals
  • SCENARIO         - Environment type (OpenArea/Mountain/Tunnel)
  • STATEINFE        - Interference state (Normal/AM/FM/Pulse)
  • COORDINATE       - 3D position coordinates
  • DELTAPOSITION    - Position error with timestamp

EKF Implementation:
  • State vector:    [x, y, z, vx, vy, vz]
  • Prediction:      Motion model with process noise
  • Update:          Kalman gain with measurement innovation
  • Covariance:      Proper propagation with Cholesky decomposition

Simulation Parameters:
  • Duration:        1000 epochs
  • Time step:       1.0 second
  • Train velocity:  20 m/s (72 km/h)
  • Tunnel entry:    Epoch 300 (300 seconds)
  • Tunnel exit:     Epoch 600 (600 seconds)
  • Random seed:     42 (for reproducibility)
