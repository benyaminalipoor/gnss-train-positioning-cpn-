# gnss-train-positioning-cpn-

شبیه‌سازی سیستم موقعیت‌یابی قطار مبتنی بر GNSS با شبکه‌های پتری رنگی

Simulation of GNSS-based train positioning with Colored Petri Nets

## 📦 محتویات مخزن / Repository Contents

- **Petrii.PDF** - مقاله اصلی / Original paper
- **gnss_cpn_simulation.py** - شبیه‌سازی کامل پایتون / Complete Python simulation
- **README_SIMULATION.md** - راهنمای جامع شبیه‌سازی / Comprehensive simulation guide
- **requirements.txt** - وابستگی‌های پایتون / Python dependencies

## 🚀 شروع سریع / Quick Start

```bash
# نصب وابستگی‌ها / Install dependencies
pip install -r requirements.txt

# اجرای شبیه‌سازی / Run simulation
python3 gnss_cpn_simulation.py
```
